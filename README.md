# PubAZ (펍아재)

> 펍아재: 국내 홀덤펍에서 치는 아재들을 낮춰 부르는 말. 이 앱은 그 사람들을 잡으려고 공부하는 앱이다.

홀덤 GTO를 혼자 공부하기 위한 PWA. 프리플랍 차트, 퀴즈, 스팟 계산기, 그리고 Claude API 기반 AI 코치가 들어 있다.

## 기능

| 탭 | 내용 |
|---|---|
| **차트** | 6맥스 100bb 프리플랍 차트 13종 (RFI 5개 + 오픈 대응 8개). 핸드를 누르면 빈도와 AI 해설 |
| **퀴즈** | 프리플랍(차트 기준 채점, 혼합 빈도는 부분 정답) · 팟 오즈/MDF/블러프/아웃츠/EV · 에퀴티 감각(프리플랍·플랍) |
| **계산기** | 내 핸드 + 보드 + 상대 레인지(또는 핸드) + 팟/베팅 → 에퀴티, 필요 에퀴티, 콜 EV, MDF |
| **플레이** | 9인 펍 토너먼트 한 핸드를 리버까지. 결정마다 팟 오즈·추정 레인지 대비 에퀴티·선택지별 EV로 채점, 끝나면 AI 핸드 리뷰 |
| **AI 코치** | 어느 화면에서든 "AI 해설 요청" → 그 스팟 정보를 들고 대화 시작. 이어서 질문 가능 |

### AI 코치 설계

- 숫자는 **앱이 계산**하고(에퀴티·팟 오즈·차트 빈도), AI는 그 숫자를 받아 **쉽게 풀어서 설명**만 한다. 그래서 AI가 숫자를 지어낼 여지가 적다.
- 시스템 프롬프트에 기본 해설집(`src/features/coach/knowledge.md`)이 들어가고, 설정의 "나만의 해설 노트"가 함께 붙는다.
- 해설집 블록은 프롬프트 캐싱으로 재사용되고, 대화 내역은 자동 캐싱된다.
- 기본 모델은 Claude Opus 5.5. 설정에서 Sonnet 5.5 / Haiku 5.5로 바꿀 수 있다. Opus/Sonnet은 서버 측 거절 대체(`fallbacks: "default"`)가 켜져 있다.
- 대화는 스팟마다 따로 저장된다(최근 40개, 브라우저 localStorage).

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 엔진·차트·퀴즈 테스트
npm run build      # dist/ 에 PWA 빌드
npm run preview    # 빌드 결과 미리보기
```

휴대폰에 설치하려면 `dist/`를 HTTPS 정적 호스팅(GitHub Pages, Vercel, Netlify 등)에 올리고, 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 된다. `base: "./"`라서 하위 경로에 올려도 동작한다.

## AI 코치 연결

설정 탭에서 두 방식 중 하나를 고른다.

### 1. 서버 키 (Vercel) — 기본값
Vercel 함수(`api/anthropic.ts`)가 서버에 등록된 키로 Claude API를 대신 호출한다. 키는 브라우저로 내려가지 않는다.

Vercel → 프로젝트 → Settings → Environment Variables:

| 이름 | 값 | 필수 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 (Sensitive로 저장) | 필수 |
| `APP_PASSCODE` | 접속 비밀번호. 등록하면 앱 설정에 같은 값을 넣은 기기만 쓸 수 있다 | 선택 |

- 환경 변수를 바꾼 뒤에는 **다시 배포**해야 적용된다 (새 커밋 푸시 또는 Deployments → Redeploy).
- `APP_PASSCODE`가 없으면 주소를 아는 누구나 그 키의 크레딧을 쓸 수 있다. 중계 함수는 앱이 쓰는 두 엔드포인트(`v1/messages`, `v1/models/*`)와 앱의 모델 3개만 허용한다.
- 로컬 `npm run dev`에는 이 함수가 없으므로 2번 방식을 쓴다.

### 2. 내 API 키
키를 그 기기의 브라우저에만 저장하고 브라우저에서 Anthropic API로 직접 요청한다(`dangerouslyAllowBrowser`). 혼자 쓰는 용도로만 안전하다.

### 키와 크레딧
- 키는 [Claude Console](https://platform.claude.com/settings/keys)에서 만든다.
- Max/Ultra 요금제의 월 API 크레딧을 쓰려면 claude.ai → 설정 → 결제 → API 크레딧에서 Console 조직을 연결하고, **그 조직에서** 키를 만든다.
- "연결 확인" 버튼은 토큰을 쓰지 않는 모델 조회로 연결을 확인한다.

## 차트 데이터

차트는 세트 → 스택 구간 → 상황 순서로 나뉜다. 차트 탭 맨 위에서 세트를 고른다.

| 세트 | 파일 | 내용 |
|---|---|---|
| 펍 토너먼트 (기본) | `src/data/sets/pub.ts` | 9인, BB 앤티. 딥(100bb+) / 미들(40~80bb) / 숏(15~20bb) / 푸시·폴드(10bb 이하). bk와 Claude의 채팅(2026-10-31)에서 정리한 펍 맞춤 범위 |
| 6맥스 캐시 100bb | `src/data/sets/cash6.ts` | 첫 버전의 학습용 근사 차트 |

**둘 다 솔버 정확값이 아니다.** 레인지 문자열만 바꾸면 직접 구한 솔버 결과로 교체할 수 있다.

```
"66+, 55:0.75, A2s+, KTo+, AJs-A6s, QJo:0.4"
 77+ = 77~AA   A2s+ = A2s~AKs   22-66, AJs-A6s = 범위   :0.4 = 40% 빈도 (뒤 토큰이 앞을 덮어씀)
```

한 상황에 액션이 여러 개면(예: 작게 열기 → 올인) 위에서부터 채운다. 앞 액션이 100%인 핸드는 뒤 액션에서 빠진다. `src/data/charts.test.ts`가 "뒤 자리가 앞 자리보다 좁지 않은지", "스택이 줄면 올인 범위가 넓어지는지"를 검사한다.

## 구조

```
src/
  poker/        카드, 레인지 파서, 7장 핸드 평가기, 에퀴티(정확 계산/시뮬레이션), 팟 오즈 계산
  data/         차트 세트 (charts.ts, sets/*.ts)
  features/
    charts/     차트 화면
    quiz/       퀴즈 화면 + 문제 생성기
    calc/       스팟 계산기
    coach/      AI 코치 (프롬프트, 해설집, Claude API 클라이언트, 대화 저장)
    settings/   설정
  play/         핸드 플레이: 9인 베팅 엔진(사이드팟), 봇 규칙, 레인지 추정, 결정 분석
  state/        localStorage 저장소
api/
  anthropic.ts  Vercel 함수: 서버 키로 Claude API 중계
```

핸드 평가기는 테스트에서 단순 무차별 평가기와 무작위 3000판을 비교해 검증한다.

## 핸드 플레이 모드

- 모두 같은 스택(딥 100bb / 미들 55bb / 숏 17bb / 푸시 11bb), BB 앤티 1bb로 시작한다.
- 봇(펍아재)은 프리플랍에서 펍 토너먼트 차트대로, 플랍 이후는 패 강도 규칙(`src/play/policy.ts`)으로 친다. 콜이 많고 블러프가 적은 펍 성향.
- 봇이 액션할 때마다 그 액션이 나올 확률로 1326개 조합의 가중치를 갱신한다. 그래서 상대 레인지 추정은 "이 봇 규칙 기준으로 정확"하다.
- 채점: 프리플랍은 차트 빈도, 플랍 이후는 선택지별 EV(현재 스트리트 기준 근사, 체크는 체크다운 가정, 멀티웨이 벳은 콜러 1명 가정)를 비교한다. **솔버 답이 아니다.**
